Signature et confidentialité

Comment l’installateur de Kaze est construit et signé, et ce que Kaze envoie sur Internet.

Politique de signature du code (code signing policy)

Pour l’instant, l’installateur de Kaze n’est pas signé : Windows SmartScreen affiche un avertissement au premier lancement. Kaze compte demander une signature gratuite au programme SignPath Foundation, réservé aux projets libres déjà connus. Cette page décrit les règles qui s’appliqueront alors.

Ce qui sera signé

Seul l’installateur Kaze-Setup-x.y.z.exe publié sur la page des versions sera signé. Il est construit à partir du code source public (licence MIT), sur les machines de GitHub Actions, par le workflow publier.yml. Chaque demande de signature sera approuvée à la main.

L’installateur contient aussi des programmes d’autres projets libres, livrés tels quels : Electron dans sa version castLabs (qui sert de base à Kaze.exe) et tor.exe du Tor Project, dont l’empreinte SHA-256 est vérifiée à chaque construction.

Politique de confidentialité

Kaze n’a ni compte, ni publicité, ni télémétrie, ni statistiques d’utilisation. Vos favoris, votre historique, vos cookies, vos paramètres et vos onglets restent sur votre PC, dans %APPDATA%\Kaze. Kordix Studio ne reçoit aucune donnée.

Connexions que Kaze fait tout seul

ServicePourquoi, et comment l’arrêter
GitHubVérifier et télécharger les mises à jour de Kaze, peu après le démarrage puis régulièrement. GitHub voit votre adresse IP et la version demandée. À couper dans Paramètres → À propos → « Mises à jour automatiques ».
GhosteryTélécharger les listes de filtres du Bouclier (EasyList, EasyPrivacy), au plus une fois par semaine. Aucune donnée de navigation n’est envoyée : le filtrage se fait sur votre PC.
GoogleTélécharger et mettre à jour le module Widevine, qui lit les vidéos et la musique protégées (Netflix, Spotify).

Connexions qui ne se font que si vous les demandez

  • Les sites que vous ouvrez, et le moteur de recherche que vous avez choisi pour ce que vous tapez dans la barre d’adresse.
  • Brume (VPN) : le réseau Tor, plus check.torproject.org et onionoo.torproject.org pour afficher l’adresse et le pays de sortie.
  • Le widget météo de l’accueil : open-meteo.com, avec la ville que vous avez saisie.
  • Le fond d’accueil « Image du jour (Bing) » : bing.com.
  • Les polices Google Fonts que vous ajoutez : fonts.googleapis.com, une seule fois, puis elles sont gardées sur votre PC.
  • Les extensions Chrome que vous installez : leur téléchargement depuis Google.

Ce que l’installateur change dans Windows

Il installe Kaze dans le dossier que vous choisissez, crée ses raccourcis et l’ajoute au menu « Ouvrir avec » des fichiers .html et .htm. Il ne change pas votre navigateur par défaut. Kaze se désinstalle depuis Paramètres Windows → Applications, comme tout logiciel.
